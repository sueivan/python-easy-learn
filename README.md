# Python轻松学（iPhone / GitHub Pages）

这是可离线使用的网页应用包，包含 24 节课和本地 Python 运行器。上传后第一次打开需要联网；加载完成后可离线使用。学习进度保存在当前浏览器中。

## 上传到 GitHub

1. 登录 GitHub，创建一个新仓库，例如 `python-easy-learn`。如果希望任何人都能访问网页，仓库选 **Public**。
2. 打开仓库，点 **Add file → Upload files**。
3. 把本文件夹里的所有文件直接拖进去，确保 `index.html` 在仓库最外层，不要只上传 ZIP。
4. 点 **Commit changes** 保存。
5. 打开 **Settings → Pages**。在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，文件夹选 `/(root)`，点 **Save**。
6. 等 GitHub Pages 发布完成，在该页面复制网址。

## 添加到 iPhone 主屏幕

1. 用 iPhone 的 **Safari** 打开刚才的 GitHub Pages 网址并等待课程加载完成。
2. 点 Safari 的 **分享** 按钮。
3. 选择 **添加到主屏幕**；打开 **作为网页 App 打开（Open as Web App）**，再点 **添加**。

## 提醒

GitHub Pages 上的网页可以被互联网访问。不要上传个人隐私或不希望公开的资料。APK 仅适用于 Android，iPhone 请使用本网页版本。
